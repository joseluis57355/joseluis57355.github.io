## 📦 Instalación

### Requisitos
- Node.js 18+
- npm o yarn

### Pasos

```bash
# Clonar el repositorio
git clone https://github.com/tuusuario/portfolio.git
cd portfolio

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Preview de la build
npm run preview
```

## 🚀 Deployment

### GitHub Pages

```bash
# 1. Actualizar vite.config.js con tu repositorio
# base: '/portfolio/' (si el repo se llama portfolio)

# 2. Compilar
npm run build

# 3. Subir la carpeta dist a GitHub Pages
# o usar GitHub Actions
```
